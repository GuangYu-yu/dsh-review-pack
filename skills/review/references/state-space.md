# 状态空间：先问"构造得出吗"，再问"怎么修"

评审最常漏的是这一问：这个形状允不允许它出错。**产出的是判断，不是另一份报告**：候选落进 `references/contract.md` 的决策点，非法组合落进 A 表。只有被明确要一份地图时，才按下面七节单独交付。

**什么时候该叠本册**：**按对象判，不按"这次想要什么产出"判**——对象有持久化状态、有恢复路径、有多个写者，或同一事实有多种表示，就在读代码之前叠。说"我这次只要发现清单"不构成不叠的理由，那只说明切分已经按文件族定了。"报告里出现两条以上「收口」"是**事后**信号：它说明当时就该叠而没叠，这时仍要补，但结论的形状已经定型，补不回切分。

## 一、维度清单

每个会影响行为的维度一行：**载体**（哪几个字段、参数、表）、**取值集合**、**来源**（输入 / 环境 / 持久化 / 编译期）、**是否独立**（按来源判，不按名字判——同一来源派生出的两个字段不独立）。

- **崩溃时机单独列**：它是"执行到哪一步中断"的切面，不是取值。
- **相位与持有者单独列**：每个持久物（journal、ckpt、映射、锁）写三件事——**谁创建它**、**谁有权让它被删**、**跨运行谁接盘**。撤除判据必须只有一个；判据若写成"本次运行是否收尾"（计数器、本次增量、命令正常返回），相位一变——中途失败后正常返回、重跑、换进程——就会把"没做完"判成"做完了"，而账面上没有任何东西记得它没做完。
- **现场版本单列**：同一套类型在不同版本数据上运行，取值集合要按版本分开写。
- **基线单列**：先写三行——审的是哪一版（commit 或版本号）、什么现场（盘 / 镜像 / LVM / 部署形态）、手上已有什么证据。结论只在这一版这一现场内成立，越过它就要重判。
- **不变量先于枚举**：任何时刻必须成立的事实，一条一句、可判真假（"目录项与块位图指向同一扇区"、"journal 里的目标与已被覆盖的范围一致"）。**不变量是可判的约束，维度清单列不全时它兜底**；写不出不变量的维度，通常只是字段，不是约束。

## 二、分类：领域固有，还是实现引入

判据：**去掉这个维度，是问题变简单了，还是问题被藏起来了？**

- **领域固有**：崩溃时机、业务本质的多样性、外部输入的不确定性、外部给定的格式与协议版本。压成统一形态只是把安全判据换成了观感。
- **实现引入**：字段组合、布尔开关、同一事实的两份表示、散落在多处的判定、只在某个模式下才有意义的字段、没有上界的兼容分支。

**只有"实现引入"的维度才配谈收敛。**

## 三、无意义组合：两条正交的轴

**3a 字段组合**——写清类型名与字段值，一句"为什么不成立"，一句"谁挡住了它"（类型 / 构造函数 / 校验函数 / 只在读取处拒 / 没人挡）。

**3b 入口绕过**——校验类型已经存在，但某些写入入口没吃它。要附三份清单：构造点、消费点、汇合点（没有唯一判定点就写"无单一汇合点"），再逐入口写"本该吃哪个校验类型、绕过后能构造出什么"。

三条门槛：

- **可构造要有证据**：公开构造函数、可见字段、builder 不校验、反序列化、`Default`。指不出的移出清单，不用"理论上"凑数。
- **分两档**：生产可达 / 仅类型可构造。**优先级只按前一档排**，混在一起假问题会压住真问题。
- **只在读取处拒不算挡住**：错误被推到下游，它就是放行侧候选。

## 四、收敛候选：写进决策点，不是另起一份

五项：收敛哪个维度 / 目标形态（和类型、显式参数、单一判定点、上界策略）/ **哪类错误由此不可构造**（答不出就不是候选）/ 触发信号 / 传导范围。

- 目标形态不止一种时，写清**为何不选另一种**——每种走法各保留、各消除了哪类错误。
- **"不升级"必须是全局判断**，不许写"本批范围外""下批再做"。
- **修在哪一级由 `references/contract.md` 定**，不由这一册定；这一册只回答"该收敛哪几个维度"。

## 五、优先级

放行侧 > 重复出现 > 依赖记忆 > 注释依赖。只有效率信号的标**"不升级，照打补丁即可"**——补丁不是缺陷，判据是下一次同类问题走的是同样的补丁，还是被结构挡住了。

## 六、不动的部分

领域固有维度逐条写一句为什么不压；"实现引入但不建议收敛"的逐条写一句阈值或代价。这一节记录的是"已经判过"，不是"还没看"。

## 七、分析边界

无法静态判定的（真实崩溃点、并发交错、真实设备布局）与无法穷举的（写清抽样方式）都要声明。没有运行时证据时，全文凡涉及现场行为的标**"仅静态"**。缺哪一节，要在开头交代，缺的那节不写。
