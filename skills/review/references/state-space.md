# 状态空间：要一张地图，不要一张发现清单

对象是类型、状态机、恢复现场，或者要回答的是"哪些组合能构造、但语义根本不成立"——用这一册。它产出的是一张**地图**（维度、分类、可构造的非法组合、收敛候选），不是逐条问题。**地图不是评审报告**：它不走 A/B/C/D 四张表，按本册的七节交付；每条结论挂依据、定级不高于依据，这两条照样在。

## 〇、动笔之前（不满足就先停）

- **版本对齐。** 报告开头写清分析的 commit 或等价版本标识，核对工作区没有未提交改动。引用的类型、函数与当前 HEAD 对不上，就先校准版本；带着版本疑点往下写，后面每一条都可能指错对象。
- **证据等级先声明。** 本次有没有运行时证据（崩溃注入、故障注入、真实设备）？有，逐点列已跑未跑；没有，全文凡涉及现场行为的一律标"仅静态"，不许写成"已验证"。
- **切片覆盖。** 按模块列切片清单，每片回答两问：本片有哪些写入入口（`pub` / `pub(crate)`）？每个入口吃的是哪个校验类型、有没有绕过？缺哪片，在第七节声明，不假装看过。

## 一、维度清单：先把空间写下来

每个会影响行为的维度一行，四样都要写：**载体**（哪几个字段、哪个参数、哪张表）、**取值集合**（枚举值、布尔、整数域、状态机节点）、**来源**（输入 / 环境 / 持久化 / 编译期）、**是否与其它维度独立**。

- **独立性按来源判，不按名字判。** 同一来源派生的两个字段不独立（版本号决定两个能力标志的取值），要在那一行写明"派生自〈谁〉"。把不独立的维度当独立，组合空间按乘积算，地图会画出根本不存在的角落。
- **崩溃时机单独列。** 它不是取值，是"操作执行到哪一步中断"的切面——每一处会落盘的步骤都是一个切面。把它混进取值集合里，就会漏掉"写了一半"这一类状态。
- **现场版本也算一个维度**：同一套类型在不同版本的数据上运行时，取值集合要按版本分开写。

## 二、分类：领域固有，还是实现引入

只有一条判据：**去掉这个维度，是问题变简单了，还是问题被藏起来了？**

- **领域固有**：崩溃时机、业务本质的多样性、外部输入的不确定性、外部给定的格式与协议版本。压成统一形态只是把安全判据换成了观感。
- **实现引入**：字段组合、布尔开关、同一事实的两份表示、散落在多处的判定、只在某个模式下才有意义的字段、没有上界的兼容分支、能在两个地方分别赋值的状态。

**只有"实现引入"的维度才配谈收敛。** 分类不是品味问题——把领域固有项列进收敛候选，等于要求把问题本身简化掉。

## 三、无意义组合：这是地图的核心

两条正交的轴，都要写：**3a 字段组合**（类型字面量能构造、语义不成立）与 **3b 入口绕过**（校验类型已经存在，某些写入入口没用它）。只做 3a 会漏掉整类"有校验但没接上"的问题。

3a：对每个"实现引入"维度，列出**当前类型或结构允许构造、但语义不成立**的具体组合，精确到类型名与字段值：

`〈类型名〉 { 〈字段〉: 〈值〉, … }` —— 一句"为什么不成立"（引不变量、协议、恢复语义的出处），加一句"谁挡住了它"（类型 / 构造函数 / 校验函数 / 只在读取处拒 / 没人挡）。

3b：每个校验类型一段，写清可见范围、**构造点清单**、**消费点清单**、**汇合点**（若存在唯一判定点，写出函数名与位置；不存在就写"无单一汇合点"），再逐入口列绕过路径：这个入口本该吃哪个校验类型、吃不到之后能构造出什么。

三条准入门槛：

- **要指得出"可构造"的证据**：公开构造函数、可见字段、builder 不校验、反序列化路径、`Default` 实现。指不出的，写"不可构造（原因）"并移到清单之外——不要用"理论上"凑数。
- **"可构造"分两档，优先级只按前一档排**：**生产可达**（现有构造路径或运行路径能到达）与**仅类型可构造**（只有结构体字面量、测试夹具能拼出）。混在一起，假问题会排到真问题前面。
- **只在读取处拒不算挡住**：错误被推到了下游，得单独标出来——它就是放行侧的候选。

## 四、收敛候选：每条五项，缺一剔除

1. 收敛哪个维度；
2. 目标形态：和类型（把字段收进一个不可分割的类型）、显式参数、单一判定点、上界策略；
3. **哪一类错误由此不可构造**——写不出这一项的，不是收敛候选；
4. 触发信号：同一类问题重复出现 / 正确性依赖调用方记得 / 语义需注释才能说清 / 错误落在放行侧；
5. 传导范围：动几个文件、要不要改签名、调用方要不要跟着改。

- **"更简洁"不是理由。** 能写的只有"这一族构造消失了"。和类型收敛的常见代价是外部调用方要多传一个值——写进传导范围，别省。
- **目标形态不止一种时，写清为何不选另一种**：每种走法各保留、各消除了哪类错误。只写"按某形态收敛"而不比较的，等于没选。
- **结论依赖现场证据的，标"证据待补"**：不要用静态推断的口气说运行时的事实。
- **上界策略**：兼容分支要么写版本上界，要么每次接纳旧形态前先回答"什么时候删它"。答不出的，那条分支是永久的。

## 五、优先级

放行侧 > 重复出现 > 依赖记忆 > 注释依赖。

- **错误落在放行侧的无条件进"必须"**：依据是代价不对称——误拒可以重试、改参数、报 bug；误放行可能不可逆。
- 只有效率信号的，标**"不升级，照打补丁即可"**。补丁不是缺陷；判据是下一次同类问题走的是同样的补丁，还是被结构挡住了。
- **"不升级"的理由必须是全局判断**（"动 N 个模块、风险大于收益"），不是"本批范围外""下批再做"——后者是把还没判的项伪装成判过的。

## 六、不动的部分

领域固有维度逐条写一句为什么不压；"实现引入但不建议收敛"的逐条写一句阈值或代价。**这一节不是免责声明**——它记录的是"已经判过、决定不动"，与"还没看"是两回事。

凡写"唯一入口""唯一判定点""唯一生产者"，都要附第三 3b 那三份清单；只给结论、不给构造点与消费点清单的，按未完成处理。

## 七、分析边界

- **哪些维度无法静态判定**：真实的崩溃点、并发交错、真实设备的扇区布局、工具输出的实际格式——静态能给的是"存在这条路径"，不是"会发生"。
- **哪些组合无法穷举**：写清抽样方式（按来源分层、按字段数设上限取笛卡尔积、只取被真实调用路径触及的组合），并声明未覆盖的部分。
- **切片覆盖与运行时证据逐点写**：缺哪片、为何缺；哪些注入点没跑、为什么没跑；每条"不升级"依赖的是代码现状还是崩溃后现场。
- 没有这一节，地图按不充分处理。

## 与评审报告的关系

地图可以直接交付。若之后还要走一次评审，把候选按对象件落进 A/B 表——**地图里"这个维度没问题"不写进发现表**，那是覆盖声明，属于停止审查的依据。
